# CampusFlow

A production-quality full-stack campus operating system unifying academics,
complaints, events, resource bookings, marketplace, and lost & found into
one platform for a college campus.

See [`SPEC.md`](./SPEC.md) for the full project specification, phase
roadmap, and technical decisions.

## Status

🚧 In development — Phase 0 (Foundation) in progress.
